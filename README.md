## Featured projects

### [Punjab SmokeWatch](https://github.com/HaseebSaair/punjab-smokewatch) | [Live demo](https://punjab-smokewatch.vercel.app)

A proof-of-concept dashboard for near-real-time crop-fire intelligence and regional smoke analysis in Punjab, Pakistan.

- Combines NASA FIRMS thermal alerts, weather and air-quality feeds, and satellite imagery.
- Uses a six-agent evidence pipeline to screen possible crop-burning events while preserving review, discard, and incomplete outcomes.
- Adds Sentinel-2 imagery with Landsat fallback, field-neighbourhood checks, and confidence-scored decisions.
- Models regional plume paths and Pakistan-India contribution shares while clearly communicating data and attribution limits.

`JavaScript` `Vercel` `Geospatial data` `Remote sensing` `Public APIs` `Agentic workflow`

### [Intelligent Invoice Automation](https://github.com/HaseebSaair/invoice-automation-n8n)

An end-to-end document-processing workflow that turns PDF and image invoices into validated, structured records.

- Extracts invoice text with Mistral OCR and converts it into structured data with an LLM.
- Detects duplicate invoices and verifies totals, line items, tax calculations, and required fields.
- Stores approved records in Google Sheets and routes exceptions through Gmail for human review.
- Processes multiple uploads through a reusable n8n workflow with configurable validation rules.

`n8n` `JavaScript` `Mistral OCR` `Groq` `Google Sheets API` `Gmail API`

### Inside LUMSU | Private academic team project

An Android application designed as a central hub for discovering and organizing campus events at LUMS.

- Built separate, role-based experiences for students and society organizers.
- Supported real-time capacity tracking, scheduling-conflict detection, and event feeds tailored by school and batch.
- Added discovery filters, including events with incentives, alongside a post-event review experience.
- Developed in a five-person team using story-pointed development cycles, isolated branches, and peer review.

`Android` `Firebase` `Figma` `Git/GitHub` `Team software development`
